In an operating system kernel, process scheduling manages the allocation of CPU execution units among ready processes. The core component is the dispatcher, which executes context switches between runnable states based on algorithmic preemption policies.

Preemptive algorithms, such as the Completely Fair Scheduler (CFS), maintain a red-black tree indexed by virtual runtime (vruntime) to ensure deterministic resource parity.

When higher priority tasks transition from I/O wait state , inter-processor interrupts (IPI) force involuntary context saves .
