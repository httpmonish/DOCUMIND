Security Vectors & Mitigations

Prompt-injection canary: 60 automated pipeline test cases (0 leaked on test suite)
Prompt Injection VERIFIED BY TEST

System instructions isolated in protected context blocks; inputs sanitized via strict XML demarcation tags and delimiter escaping.

Vector: System delimiter & XML breakout
Vector Poisoning PARTIAL

Cryptographic SHA-256 ingestion hashes enforce chunk immutability and deduplication; does not prevent semantic embedding poisoning if malicious documents are indexed.

Vector: Embedding payload spoofing & semantic poisoning
Model Jailbreaks PARTIAL

Post-generation validator drops uncited claims and unverifiable markers, but relies on LLM instruction adherence to resist adversarial jailbreaks.

Vector: Roleplay & DAN exploit variants
Denial of Wallet VERIFIED BY TEST

Token-bucket rate limits (10 asks/min, 20 API req/min) and two-phase spend ledger ($2.00/day global, $0.25/day per IP) failing closed to retrieval.

Vector: Unlimited token drain loops
Path Traversal VERIFIED BY TEST

Filename sanitization via `safe_upload_name`, Windows reserved name rejection, and `is_relative_to` path checks on upload and deletion endpoints.

Vector: ../../etc/passwd read attempts
XSS Injection PARTIAL

Untrusted document text is sanitized during prompt assembly and rendered via textContent in core views; dynamic metrics require safe DOM binding.

Vector: Script tag injections via chunk
